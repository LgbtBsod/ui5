Codex apply instructions
========================

1. Replace only the files included in this patch pack.
2. Prefer applying `ui5_final_fix_pack.patch` first; if patch application fails, replace files manually from the changed-files archive.
3. After applying, run these checks locally:
   - `npm install`
   - `npm run build`
   - `npm run build:dist`
   - `npm run validate`
4. Verify that these conditions are true:
   - bootstrap/theme uses `sap_fiori_3`, not `sap_horizon`
   - `sap.ui.export` is declared in `manifest.json`
   - both analytics export and search export route through Spreadsheet export, not XML `.xls` generation
   - `package.json`, `ui5.yaml`, `.editorconfig`, `.stylelintrc.json`, `README_BUILD_AND_VALIDATE.md` exist
5. Grep checks:
   - `grep -R "sap_horizon" -n app` should return no productive runtime references
   - `grep -R "ExcelExport.download" -n app` should return none or only compatibility wrapper use
   - `grep -R "new ODataModel" -n app` should not show new productive-path additions
6. Do not change the test bootstrap core URL.
7. If any verification fails, inspect the touched files only; do not broad-rewrite unrelated modules.
