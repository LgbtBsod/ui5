# Security Policy

## Supported Versions

Only the latest `main` branch and release branches tagged from it are supported.

## Reporting a Vulnerability

Please report security issues privately to the maintainers:

- Email: security@example.com
- Include: impact, affected flow, reproduction steps, and suggested mitigation.

Do not open public issues for unpatched vulnerabilities.

## Response Targets

- Initial triage: 2 business days
- Mitigation plan: 5 business days
- Patch release target: based on severity and exploitability
