# Generated Artifact Ownership

- `app/` is the editable source of truth for UI5 application logic, views, i18n, and styles.
- `dist/` is build output generated by `npm run build`. Treat it as derived runtime packaging, not as a second place to patch behavior.
- `app/fixed_output/` is a legacy snapshot used for audit comparison and contract evidence. It mirrors selected source files but is not the canonical implementation target.
- When source and generated folders disagree, fix `app/` first and regenerate `dist/`; do not hand-maintain duplicate logic in `dist/` or `app/fixed_output/`.
