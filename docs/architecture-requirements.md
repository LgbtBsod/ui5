# Architecture Requirements (Safety Pack)

## Session lifecycle
- `sessionId` is generated once at startup in `Component.js`.
- `sessionId` is read via `StatePaths.SESSION_ID` and must not be regenerated by UI actions.

## Lock lifecycle
- Enter edit must call `LockPort.acquire({ rootId, sessionGuid })`.
- Same-user lock in another tab must trigger takeover confirm flow.
- Lock killed/lost must force READ mode and disable autosave immediately.

## Autosave guards
Autosave tick is allowed only when:
- `editMode === EDIT`
- `lockState === LOCKED`
- `dirty === true`

## Effect contract
- Confirm/warn notifications are emitted as Effects.
- `MessageBox` usage is centralized in `EffectApplier`.
