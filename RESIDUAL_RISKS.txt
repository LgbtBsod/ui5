2026-03-27 Final Production-Readiness Residual Risks

1. Productive SAP stream support still depends on system-side deployment.
- Repo contract, local metadata, frontend transport, and mock Gateway are aligned to media upload on `AttachmentSet`.
- Productive SAP Gateway still requires the corresponding stream handling to be implemented and activated in the target system.

2. Legacy SAP internal CSS remains quarantined, not fully removed.
- Remaining `.sap*` selectors are now explicitly whitelisted and documented.
- This is governed debt, not hidden debt, but it is still renderer-coupled styling and should be reduced in later visual refactors.

3. Mock Gateway pytest runs can still be stateful across repeated local executions.
- `python -m pytest backend/mock_gateway/tests/test_attachment_upload_policy.py` passes.
- Repeated ad hoc pytest runs against the same persistent `gateway.db` can still produce uniqueness/schema-noise unless the DB is reset.

4. Framework/runtime fragmentation is reduced but not fully eliminated.
- `ControllerRouteRuntime` and `FeedbackCoordinator` were removed.
- `SearchCommandPolicy` was also removed and absorbed by the search controller boundary.
- `DetailCommandPolicy` was also removed and absorbed by the detail controller/runtime boundary.
- Larger bootstrap/component/runtime clusters still need a deeper merge pass if the repo wants a stricter SRP end-state.

5. Raw UI fallback text is now governed, but legacy `ControllerTextRuntime`/`ControllerModelRuntime` helper usage remains broad.
- The current pass removed live fallback copy from active analytics/search runtime and detail info-card labels/tooltips.
- Helper consolidation is still possible later, but it is not required to keep the current production baseline compliant.

6. DOM and CSS debt is frozen behind quarantine, not erased.
- `sap-internal-css-gate.js` and `dom-hack-gate.js` now enforce reasoned allowlists with size caps.
- This prevents silent growth, but renderer-coupled files listed in the allowlists still remain as managed technical debt.
