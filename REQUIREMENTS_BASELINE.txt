TZ 2.1 production-ready baseline

Stack
- SAPUI5 1.71 target
- SAP Gateway OData V2
- CDS / SADL read path
- BOPF modify path
- Microsoft Edge only, no IE support

Validation baseline
- npm run lint:js
- npm run lint:css
- python -m pytest -q
- npm run build
- powershell -ExecutionPolicy Bypass -File scripts/local-launch-smoke.ps1

Build prerequisites
- Node.js with npm
- Python on PATH for backend mock tests
- Local build currently relies on repo-owned fallback dist + preload generation because public npm does not resolve @sapui5/distribution-metadata@1.71.70
- Official SAPUI5 preload build still requires SAPUI5 registry access

Project rules that remain mandatory
- JSONModel runtime pattern remains the frontend state pattern
- masterData>/runtime/* remains the runtime settings source of truth
- search exact = AND, loose/inexact = OR
- backend fetch limit and visible chunk size stay separate
- delete target flow stays canonical modification pipeline
- lock flow stays acquire/status/heartbeat/release with ForceTakeover on acquire only

Truth corrections
- DB_KEY / PARENT_KEY cannot currently be claimed as fully restored frontend command-flow canon
- phased detail loading cannot currently be claimed as closed
- metadata-first attachments cannot currently be claimed as fully closed while Value remains active in serialization/open fallback
