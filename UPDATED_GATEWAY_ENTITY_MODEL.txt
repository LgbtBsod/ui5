UPDATED GATEWAY ENTITY MODEL

Command/read split
- ChecklistRootSet: aggregate root read model.
- ChecklistBasicInfoSet: supporting read model for header/basic detail data.
- ChecklistCheckSet: child read model.
- ChecklistBarrierSet: child read model.
- AttachmentSet: attachment metadata read model.
- ChecklistSearchSet: search/list projection.
- ChecklistPermissionSet: detail permission projection.
- ChecklistCreatePermissionSet: create capability projection.
- DictionaryItemSet: value help / dictionary read model.
- PersonVHSet: people value help read model.
- LockStatusSet: lock status read-only projection.
- LastChangeSet: change tracking / freshness projection.
- SimpleAnalyticalSet: lightweight analytical read.
- WorkflowAnalyticsBreakdownSet: heavyweight analytical breakdown read.
- AnalyticsRefreshStateSet: analytics refresh state projection.

Truth notes
- Entity sets are used as read models and capability projections.
- Mutations are command-driven through function imports, not direct DELETE of aggregate or child entities.
- AttachmentSet is not enough by itself to prove a fully metadata-first attachment contract, because frontend still treats Value as a live compatibility field in open/save paths.
- ChecklistCheckSet and ChecklistBarrierSet are still eagerly loaded on initial detail open in current frontend read runtime.
